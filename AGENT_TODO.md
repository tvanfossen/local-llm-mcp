### Key Lessons Learned
1. **Trust the LLM**: Removed auto-add, then re-added it as "graceful completion" - works perfectly
2. **Remove Heuristics**: Bad assumptions block valid tool calls - validate structure only
3. **Test with Real Examples**: Calculator revealed all the bugs - real examples > synthetic tests
4. **Verbose Logging**: Essential for debugging - never truncate during development
5. **DRY Principles**: Centralized prompts, schemas, and templates prevent drift
